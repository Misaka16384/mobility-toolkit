## 2024-05-24 - Python 3.9+ math.lcm/gcd Optimization
**Learning:** Python 3.9 introduced `math.lcm` and updated `math.gcd` to accept an arbitrary number of arguments. These C-level implementations are significantly faster than manual loops or `functools.reduce` in Python. We measured a ~5x speedup for GCD and ~1.5x speedup for LCM arrays using `math` vs loop/reduce alternatives.
**Action:** Always prefer `math.lcm(*args)` and `math.gcd(*args)` over custom Python loop implementations or `reduce` wrappers when optimizing arrays of integers. Watch out for edge cases with empty arrays (handle with conditionals like `math.lcm(*arr) if arr else 1`).
